The short version

  • Your commands are saved in one secret gist on your own GitHub account.
  • With Sign in with GitHub, requests go through our sign-in function, which adds your GitHub token and passes them on. It never stores or logs your commands.
  • With a personal access token (Advanced), your browser talks to GitHub directly and nothing passes through us.
  • One cookie, and only with Sign in with GitHub: it holds your encrypted GitHub token so you stay signed in. No analytics or trackers inside the app.
  • You can export everything, delete the gist, or revoke the token at any time.

What GistVault handles

GistVault runs entirely in your browser. While you use it, it works with:

  • Your commands — titles, command text, tags, shell, notes, whether each one is a favorite and how often you copied it.
  • Your GitHub token — used only to call api.github.com on your behalf. With Sign in with GitHub it is a token issued to the GistVault GitHub App, which can reach only your gists, expires every 8 hours and is renewed automatically.
  • Your public GitHub profile — your username, display name and avatar, shown in the account menu.
  • A few local settings — the ID of your vault gist, a random device ID used when merging edits, and your theme choice.

Values you type into placeholders (for example a host name or pod name) are used once to build the copied command and are never saved.

Where it is stored

What GistVault stores, where, and for how long
Data Where How long
Commands Secret gist on your GitHub account (gistvault.json) Until you delete them or the gist. GitHub keeps gist revision history.
GitHub token (Sign in with GitHub) An encrypted, HttpOnly cookie in your browser (__Host-gv_session). Our function decrypts it only to make each request, and keeps no copy. Until you sign out, or after 30 days without use. The token inside is replaced every 8 hours.
Sign-in check (Sign in with GitHub) An encrypted cookie during sign-in (__Host-gv_oauth) Up to 10 minutes; deleted when you come back from GitHub
GitHub token (personal access token) This tab’s memory; optionally the tab’s session storage Until you reload, sign out, or close the tab
Vault gist ID, device ID Your browser’s local storage Until you clear site data
Theme choice Your browser’s local storage (only if you pick Light or Dark) Until you change it or clear site data
Placeholder values Nowhere — memory only while the dialog is open Discarded when you copy or cancel

Neither kind of token is ever written to local storage, which survives browser restarts and is readable by any script on the page. Page scripts can’t read the sign-in cookie either.

Who can see your vault

A secret gist is unlisted, not private. It doesn’t appear in search or on your profile, but anyone who has its URL can read it. GistVault never shows that URL in its interface.

  • You — through GistVault or directly on gist.github.com.
  • GitHub — which hosts the gist under its own privacy statement.
  • Anyone with the link — if you share it, or it leaks.

That is why GistVault checks for passwords, API keys and tokens before every save. Keep secrets out of your vault — use a placeholder such as {{ '{{' }}API_KEY{{ '}}' }} instead. See the security model for details.

What we don’t collect

  • No GistVault accounts, emails or passwords.
  • No cookies other than the two sign-in cookies above, and none for tracking.
  • No analytics, tracking pixels or session recording inside the app.
  • No third-party scripts, ads or CDNs — fonts are served from our own domain.
  • No copies of your commands, token or profile stored on any server we run. Your token is kept only in your own browser’s cookie.

GitHub and hosting

GitHub

Your vault is read and saved through api.github.com — straight from your browser with a personal access token, or through our sign-in function with Sign in with GitHub. GitHub processes that data under the GitHub General Privacy Statement.

Hosting

The app’s files and the sign-in function run on our hosting provider, Vercel. Like any web host, it may log standard request details such as IP address, browser, time and the address requested to operate and secure the service. With Sign in with GitHub, those addresses include your vault gist’s ID. The function never logs request bodies, commands or tokens.

Your controls

  • Export — use Export JSON in the vault to download every command.
  • Sign out — clears the vault from this tab, and the token or sign-in cookie. Sign out and remove access also revokes GistVault’s authorization on GitHub.
  • Revoke the token — on GitHub under fine-grained tokens or classic tokens; for Sign in with GitHub, under Authorized GitHub Apps.
  • Delete your data — delete the gist described as “GistVault data” on gist.github.com.
  • Clear local settings — clear this site’s data in your browser settings.
